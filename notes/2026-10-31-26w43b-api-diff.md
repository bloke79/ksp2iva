# API diff: 26w41a to 26w43b (2026-10-31)

**Status: applied 2026-10-31.** The fix is in the repo (1.0.0), the SDK project is on template 26w43a and builds; see CLAUDE.md "Unity SDK project". Not yet flown.

Old: the SDK project's `Packages\KSP2_x64` (26w41a). New: the installed game, changed 2026-10-31 15:05.
The install has no version string. `Ksp2Redux.dll` is build 0.0.9792, which dates to about 2026-10-23 (week 43), so it fits 26w43b.
Method: public metadata of both sides read with Mono.Cecil, then a real compile of `Code/*.cs` against the new `Managed` folder.
`unity-check` can't test this: it compiles against the SDK project, so it stays clean on 26w41a.

## Result
**One breaking change, and it's mechanical.** With it fixed in a scratch copy, the runtime code compiles against the new DLLs with 0 errors.

| Change | Effect on the mod |
|---|---|
| `ReduxLib.Configuration`, `.Input`, `.Logging` moved to `SpaceWarp2.API.*` | 56 compile errors, all from 11 `using` lines (below) |
| `ReduxLib.dll` and `SpaceWarp2*.dll` no longer in the game | The current `IVA.dll` references `ReduxLib`, so expect it to fail to load on the new game. Not tested: Matt hasn't launched it |
| Game code moved from `Assembly-CSharp.dll` to `Ksp2Redux.dll` | None. Both old assemblies are stubs that forward 7,400 types |
| `KerbalMod.SWConfiguration`, `SWLogger` | Types moved as above. Used the same way |
| `KerbalMod` gained `Enabled`, `OnCampaignLoaded`, `OnCampaignUnloading` | Optional. Not needed |
| Public types removed (`KSP.Modding.*`, wheel physics `VehiclePhysics.*`, reentry VFX, mesh jobs) | None used by the mod |

`ConfigValue<T>` and `KeyboardShortcut` have identical public members on both sides. Whole-API count: 5,219 lines removed or changed, 2,427 added;
most are the namespace move and types the mod doesn't touch.

## The fix (don't apply until the SDK project is on 26w43b: it breaks the 26w41a compile)
- `using ILogger = ReduxLib.Logging.ILogger;` becomes `SpaceWarp2.API.Logging.ILogger` in CabinAo, CustomInterior, Doors, FreeMove, Hatches, Interact, LiveInstruments, Sounds.
- `CustomInterior.cs:15` `using ReduxLib.Logging;` becomes `using SpaceWarp2.API.Logging;`.
- `IVAPlugin.cs:21-22` `using ReduxLib.Configuration;` and `.Input` become `SpaceWarp2.API.Configuration` and `.Input`.
- `notes/local-style.md` and CLAUDE.md name `ReduxLib`: update them too.

The Editor scripts don't use ReduxLib. They were not trial-compiled (they need UnityEditor).

## What this diff can't prove
- Behaviour. Same signatures don't mean same results: the camera shot override, `SetKerbalLocation`, `TryStartEVA`, gravity and the camera-rig crash all need a flight.
- Assets. The mod's bundle and shaders were built on the old template. The `IVA EyeTransform` lookup, stock interior prefabs and the portrait booth are names in game data, not API. Redux also rebuilt its bundles (`Redux/BundleConversion`).
- `mod.config.json`, CLAUDE.md and `knowledge/ksp2-redux-modding.md` still say 26w41a: update them after the move.
